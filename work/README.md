# work/

All outputs go here, one folder per project, named with the date it started:

    work/2025-03-10-pipeline-report/
    work/2025-03-17-list-cleanup/

Also holds `journal.md`, a running log of what you did each day. `/weekly-recap` reads it.

Keep scripts you ran, inputs (as copies), and the output of each run in the folder, so a result can be reproduced or reviewed later. This folder is gitignored.
