Write the weekly recap. Extra input from me: $ARGUMENTS

## Sources (read-only)
1. `work/journal.md`: entries from the last 7 days.
2. Task board (Notion or similar MCP): items completed this week.
3. Slack: notable highlights in the team channels I name in `CLAUDE.md`.
4. CRM: pipeline created and closed this week versus last week.
5. Ads and analytics: spend, results, and trend versus last week.
6. Any scripts in `system/` that produce a weekly report: run them and use the output.

If a source is not connected, leave it out and note it at the bottom.

## Structure
- Executive summary: 3 to 5 sentences written for someone who reads nothing else. What moved, what is at risk, what is next. Numbers over adjectives.
- Wins
- Pipeline week over week
- Ads and channel performance
- Work log (grouped by project, from the journal)
- Concerns
- Next week focus

## Rules
- Every number must trace to a source above. If you cannot source it, leave it out.
- Save the draft to `work/YYYY-MM-DD-weekly-recap/recap.md`.
- Add one line to `work/journal.md` noting the recap was drafted.
- Posting to Slack or publishing to Notion: confirm first. Show me the exact text and destination, then wait for a yes.
